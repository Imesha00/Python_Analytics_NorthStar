# NorthStar Database Analytics

## Project Overview
This project focuses on database analytics and data processing using Python, R, SQL, and MongoDB technologies. The analysis was conducted using operational datasets related to customer management, delivery services, complaints, incidents, hubs, and vehicle operations.

The project demonstrates practical implementation of:
- SQL queries in R using sqldf
- Data analytics and visualisation in R
- Python data preprocessing and transformation
- MongoDB NoSQL database operations
- Query optimisation with indexing
- GitHub version control integration
